# Пример прогона агента — отчёт, который сдаётся

Отчёт, который агент сформировал по документу организаторов `docs/requirements.md` — без ручных правок.

| | |
| :--- | :--- |
| Команда | `python -m reqval docs/requirements.md out/report.md` |
| Модель | `anthropic/claude-sonnet-5.5` через OpenRouter, ответ по строгой JSON-схеме |
| Версия агента | тег `v1.0` (коммит `33249c5`) |
| Дата | 27.11.2026, 12:10 (Алматы); 13 обращений к модели без повторов, 132 с, $0.74 |
| Итог | **НЕ ГОТОВ**: 59 требований, 64 дефектов (5 критичных, 43 значительных, 16 незначительных) |
| Журнал | `report.llm.jsonl`, SHA-256 `67239c4610962c98…` — совпадает с указанным в паспорте отчёта |

Файлы:
- `report.md` — отчёт (паспорт, нарезка, проверка каждого требования и набора, сводка, итог);
- `report.json` — то же в машиночитаемом виде;
- `report.llm.jsonl` — журнал всех обращений к модели: промпты (SHA-256), сырые ответы, токены, стоимость.
  SHA-256 журнала указан в паспорте отчёта — по нему видно, что отчёт сформирован этим прогоном.

У модели Claude не задаётся `temperature` (постоянное мышление), поэтому повторный прогон может дать немного
другие формулировки и число замечаний; основные дефекты стабильны от прогона к прогону.
